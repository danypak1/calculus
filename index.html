What a question looks like

As x → 2, the function f(x) = (x² − 4)/(x − 2) is undefined at x = 2 itself. The limit as x approaches 2 is

A0, because the numerator is 0 there
Bundefined, the same as f(2)
C4
D2
✗ Not quite — the answer is (C) What this mistake means: you are reading the limit as a statement about the value at x = 2. It never is. Cancel the factor and the function is x + 2 everywhere except that one point, so as x closes in from either side the value closes in on 4 — which is exactly what a limit asks. A function can have a limit at a point where it is undefined; that is the whole reason limits exist.
